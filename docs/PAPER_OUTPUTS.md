# Paper Output Contract

The complete local paper surface is regenerated with one command:

```bash
uv run -m scripts.paper.regenerate
```

It prepares the frozen dataset, refits `results/clean_model/powertrace_v1.json`,
and regenerates the main and appendix outputs below. The final
`results/paper/manifest.json` binds every artifact family to exact bytes. A
missing producer or output fails the command. Generated plots and values are
never edited by hand.

## Main paper

| Claim | Allowlisted output | Evidence contract |
| --- | --- | --- |
| Request-phase timing | `results/paper/timing_{prefill,decode}_parity.pdf` | Frozen timing split and the regenerated release; see `timing_parity_manifest.json` |
| End-to-end simulator fidelity | `results/paper/selected_model_fidelity_table.tex` | One regenerated release scored on supported held-out measured runs; no coverage-specific refit |
| Representative traces | Four `results/paper/power_trace_*_release_1s.pdf` panels | One held-out configuration at 0.125, 1, 2, and 4 requests/s; see `selected_representative_traces.json` |
| Facility consequences | `figures/azure_figure_{1..5}_*.pdf` and `figures/azure_oversubscription_{capacity,lines}.pdf` | All 240 node traces generated by the same release; see `azure_figure_manifest.json` and `results/eval_paper/azure_*` |
| Facility sizing | `results/eval_paper/azure_facility_sizing_table.tex` | Derived from the regenerated facility metrics |

The selected replay retains `selected_replay_per_run.csv` and its provenance
manifest. Values are matched non-overlapping one-second per-GPU means. Meter
response is reset at run boundaries. The facility generator reports node watts
and applies tensor-parallel scaling once.

## Appendix transfer evidence

The files under `results/paper/appendix/` are boundary evidence, not zero-shot
validation:

| Evidence | Outputs | Required label |
| --- | --- | --- |
| Dense and MoE Qwen transfer | Two `power_trace_qwen3_*_transfer_1s.pdf` panels and `transfer_trace_report.json` | Retrospective idle/platform-calibrated transfer |
| BurstGPT arbitrary arrivals | Three `power_trace_burstgpt_*_idle_1s.pdf` panels and `burstgpt_idle_transfer_report.json` | Retrospective idle-calibrated arbitrary-arrival transfer |
| OpenHands agent workload | `openhands_platform_calibrated_prediction_overlay.pdf` and `openhands_platform_calibration.json` | Retrospective few-shot platform calibration; not a cache-effect claim |

Every family retains the exact plotted one-second samples. The JSON reports
record the regenerated source artifact and the target-derived calibration.

## Excluded evidence

Candidate-selection, ablation, residual, metric-audit, coverage-refit, and
rate-4 diagnostic plots remain development evidence. Historical GMM-BiGRU
results live in `archive/gmm_bigru_v1/`. Neither may replace an allowlisted
output. External sealed scoring and disaggregated inference are deferred and
are explicitly absent from the local manifest.

The implementation scripts under `power-test/` are internal producers. They
are not independent paper entry points; the maintained interface is
`scripts.paper.regenerate`.
