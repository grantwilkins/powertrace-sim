# Historical research artifacts

This directory preserves figures and prototypes excluded from the maintained
PowerTrace-Sim surface.

- `root_figures/` contains the previously tracked top-level diagnostic PNGs.
- `figures/` is a local, ignored archive of the former top-level figure tree.
  Those files remain in the working copy but are reproducible or recoverable
  from prior Git history; they are not current paper outputs.
- `eval_paper/` contains tracked tabular outputs from retired appendix,
  baseline, feature-sufficiency, and trace-fidelity pipelines.
- `results/` contains rejected feature scorecards and superseded ledger and
  two-price fits.
- `archive/powermodel_v0/` contains the retired alternative bottom-up model.

Current-model paper figures are tracked under `results/paper/`.
